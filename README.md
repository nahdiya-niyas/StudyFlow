# 🎓 StudyFlow

A student productivity and study planning web application designed to help students organize their notes, tasks, and study sessions in one place.

## ✨ Features

* 🔐 User registration and login
* 📝 Create, edit, and delete notes
* 📋 Create and manage tasks
* ✅ Track completed and pending tasks
* 📅 Plan study sessions
* ⏱️ Independent study-session countdown timers
* 👤 User profile
* 📊 Productivity dashboard
* 📱 Responsive and modern interface

## 🛠️ Technologies

* **Python**
* **Flask**
* **HTML5**
* **CSS3**
* **JavaScript**
* **SQLite**
* **Flask-Login**
* **Werkzeug**

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/nahdiya-niyas/StudyFlow.git
cd StudyFlow
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```

Then open the local address shown in the terminal.
